**JDK** -> Java Development Kit
**JRE** -> Java Runtime Environment
**JVM** -> Java Virtual Machine

- Java byte-code can run on any machine but JVM implementations are platform independent for each Operating System.

# JDK

- Provides **Tools** and **Libraries** to develop Java Applications
- Includes **Compiler(javac)**, **Debugger**, and **Utilities** like jar and javadoc.
- Provides **JRE** to run Java programs.
- Used by developers to write, compile and debug code.

- JDK is platform dependent.
- .java is called source file.

# JRE

- Environment to **run Java programs**, intended for **End Users** only.
- Does not include development tools and hence does not support compilation & debugging.

- Platform dependent

##### Working

- Loads compiled .class files into memory.
- Ensures security & validation of byte-code.
- Uses JVM (interpreter + JIT compiler) to execute instructions.


# JVM

- Core engine, converts byte-code in machine code.
- Performs memory management and garbage collection.
- Provides portability.

- Modern JVMs rely heavily on Just-In-Time (JIT) compiler for performance.

##### Working

- Class Loader loads byte-code into memory.
- Linking $\rightarrow$ Performs verification, preparation and resolution.
- Initialization $\rightarrow$ Executes class constructors and static initializers.
- Execution $\rightarrow$ Interprets byte-code into native code.
