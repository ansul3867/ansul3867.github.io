
- Unique names given to programming elements like variables, classes, methods, packages, interfaces, etc.


```run-java
class Geeks{ //'Geeks' is Class-Name
	public static void main (String [] args){ 
		//'main' is a Method-Name
		//'String' is a predefined Class-Name
		//'args' is Parameter-Name
		
		int x = 9; //'x' is Variable-Name
		}
	}
```


##### Rules for naming Identifiers

- If these rules are not followed, we get **Compile-Time Error**.
- Also valid in C & C++.

1. Only allowed characters - all alphanumeric characters{(A-Z), (a-z), (0-9)}, '$' and ' __ '
   No other special characters are allowed.
2. Can **not** start with a digit.
3. They are **Case-sensitive.**
4. No limits on length, advisable to use optimum length - 4 to 15 characters only.
5. Reserved Words cab't be used as an identifier.

- Java has 53 reserved words
  (Including 50 keywords and 3 literals)
