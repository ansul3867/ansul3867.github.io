
- Reserved words having some predefined meanings and are used by Java Compiler to represent some predefined actions which can not be used as identifiers.

- 'const' and 'goto' are reserved, even though, not currently used in Java.
- 'true', false' and 'null' $\rightarrow$ look like keywords, but are literals.
- Keywords are case sensitive.


#### Data Type Keywords


- Defines variable type & specify the kind of data they can hold.

| Keyword | Function                                          |
| ------- | ------------------------------------------------- |
|         |                                                   |
| boolean | Defines a variable that holds true or false       |
| byte    | Defines an 8-bit signed integer                   |
| char    | Defines a 16-bit unicode character                |
| short   | Defines a 16-bit signed integer                   |
| int     | Defines a 32-bit signed integer                   |
| long    | Defines a 64-bit signed integer                   |
| float   | Defines a 32-bit floating point number            |
| double  | Defines a 64-bit floating point number            |
| void    | Specifies that a method does not return any value |

#### Control Flow Keywords

- Control the execution flow of a program including loops, branching and jumps.

| Keyword  | Function                                                 |
| -------- | -------------------------------------------------------- |
|          |                                                          |
| if       | Executes code when condition is true                     |
| else     | Defines an alternate block when an if condition is false |
| switch   | Selects one block of code among multiple options         |
| case     | Defines an individual branch in a switch statement       |
| default  | Defines the block executed if no case matches            |
| for      | Starts a for loop                                        |
| while    | Starts a while loop                                      |
| do       | Starts a do-while loop                                   |
| break    | Terminates the nearest loop or switch                    |
| continue | Skips to the next iteration of the loop                  |
| return   | Exits from a method & optionally returns a value         |


#### Exception Handling Keywords

- Used for handling and managing runtime errors.

| Keyword | Function                                                 |
| ------- | -------------------------------------------------------- |
|         |                                                          |
| try     | Defines block of code to test for exceptions             |
| catch   | Defines block of code to handle exceptions thrown by try |
| finally | defines block always executes after try & catch          |
| throw   | used to manually throw an exception                      |
| throws  | Declares the exceptions a method can throw               |
| assert  | Test assumptions duting program execution for debugging  |


#### Object-Oriented Keywords

- Defines class, objects, interfaces: inheritance & encapsulation properties

| Keyword    | Function                                                     |
| ---------- | ------------------------------------------------------------ |
|            |                                                              |
| class      | Declares class                                               |
| interface  | Declares interface                                           |
| extends    | Indicates inheritance from a superclass                      |
| implements | Indicates that a class implements an interface               |
| new        | Creates new objects                                          |
| this       | Rrefers to the current objects                               |
| super      | Refers to the superclass of the current object               |
| abstract   | Declares class/method that must be implemented in a subclass |
| final      | Prevents inheritance, overriding, or modifications           |
| static     | Declares class level variables or methods                    |
| sealed     | Restricts which class can extend a fiven class               |
| permits    | Specifies the subclasses allowed to extend a sealed class    |


#### Access Control Keywords

- Defines visibility/accessibility of classes, methods and variables.

| Keyword   | Function                                            |
| --------- | --------------------------------------------------- |
|           |                                                     |
| public    | Accessible from anywhere in the program             |
| protected | Accessible within the same package or by subclasses |
| private   | Accessible only within the same class               |


#### Package and Import Keywords

- Organize classes & access external code

| Keyword | Function                                     |
| ------- | -------------------------------------------- |
|         |                                              |
| package | Defines a namespace for classes              |
| import  | Allows access to classes from other packages |


#### Multithreading & Synchronization Keywords

- Handles concurrent execution of code and thread safety.

| Keyword      | Function                                                            |
| ------------ | ------------------------------------------------------------------- |
|              |                                                                     |
| synchronized | Defines critical sections that only one htread can access at a time |
| voaltile     | Indicates that a variable may change asynchronously                 |


#### Memory Management & Object Serialization

- Handles object persistence, garbage collection, and native method calls.

| Keyword   | Function                                                 |
| --------- | -------------------------------------------------------- |
| transient | Excludes a variable from serializarion                   |
| native    | Specifies method is implemented in native(non-Java) code |


#### Modifier and Utility Keywords

- Defines additional behaviors & precision control

| Keyword  | Function                                                            |
| -------- | ------------------------------------------------------------------- |
|          |                                                                     |
| strictfp | Ensures consistent floating point calculations across all platforms |


#### Reserved(Unused) Keywords

- 'const' & 'goto'


#### Special Literals


| Literal | Function                                     |
| ------- | -------------------------------------------- |
|         |                                              |
| true    | Represent the boolean value type true        |
| false   | Represent the boolean value type false       |
| null    | Represent the absence of any reference value |



- Java is statically typed language i.e., type of variable is known at compile time improving performance, reducing runtime errors
  Dynamically typed language $\rightarrow$ determine variable type at runtime.
